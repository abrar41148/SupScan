# Step 5. Compare two scans

Each finished scan is kept. Pick two to see what changed.

## What changed

A scan from the page is saved. The Compare selects list those scans, newest first. The label is the time, the folder or repo name, and the short commit.

Pick This scan and Previous scan. The page groups findings into:

- Still open: in both scans
- Newly found: only in this scan
- Gone: only in the previous scan

A finding matches on ecosystem, name, version, and advisory id. A version change is a new finding and a gone finding.

Ignored findings stay marked inside those groups. Open findings only still hides them.

Opening a report file does not save a scan.

## Not in this step

No extra pages. The single scan stays on screen until two different scans are chosen.

## Done when

Two saved scans of the same target show a finding that appeared, one that disappeared, and one that remained.
